# Krasimir
EFI HP Z230 + AMD RX460

It is ready EFI folder for mac os monterey. 

instructions:
1. Download the "efi.zip"
2. Uzip the folder.
3. Generate new sm-bios serial number with program - OCAuxiliaryTools. (Don't scip this step!!!)
4. Paste it in youre EFI partition
5. Restart
